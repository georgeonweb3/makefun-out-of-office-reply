Build a Python program (main.py) for the make.fun competition "The Funniest AI Out-of-Office Reply".
The program must write exactly one out-of-office auto-reply, shorter than 160 characters, to /output/entry.txt as UTF-8 text, producing the same line on every run.
The reply must sound like an AI agent on holiday, land a real laugh with an unexpected twist, read as a machine talking about itself, and work as a clean one-line auto-reply, steering clear of beach, inbox and back-soon cliches.
No network, no randomness, no external files.
